# IT Activity Tracker Roadmap

## Phase 1 — Foundation
- Dockerized Laravel 13 + Livewire 4
- PostgreSQL
- Nginx
- Queue + scheduler
- Authentication starter kit

## Phase 2 — Data model
- User-owned activities
- Categories
- Status / priority enums
- Start / completion timestamps
- Follow-ups
- Evidence / reference fields

## Phase 3 — UX
- Dashboard
- Daily activity log
- Fast add/edit activity workflow
- Search and filters
- Responsive layout

## Phase 4 — Reporting & exports
- Report builder
- Date range and activity filters
- Column chooser
- Drag/drop or up/down column ordering
- Saved per-user report layouts
- Excel / CSV / PDF exports

## Phase 5 — Notifications
- Last-Friday monthly report reminder
- In-app notifications
- Optional email notification channel

## Phase 6 — Security & operations
- Authorization policies
- Audit trail
- Database backups / restore
- Rate limiting
- Automated tests
- Production Docker profile
